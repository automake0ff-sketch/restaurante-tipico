# TÍPICO EXPERIENCE + BUSINESS

Plataforma digital personalizada para **Típico Barra de Tapas**  
Pagés del Corro 86, Triana, Sevilla.

**Lema:** SAME SAME BUT DIFFERENT

## Qué incluye

### TÍPICO EXPERIENCE (público)
- Portada móvil-first premium
- Carta digital con categorías y filtros (vegetariano, vegano, picante…)
- Detalle de platos con avisos de alérgenos y “pendiente de confirmación”
- **TÍPICO FOOD GUIDE** — asistente de recomendaciones (solo productos de la carta)
- Lista de espera digital (cliente + vista staff)
- Multidioma base (ES / EN / FR)
- Enlaces reales a teléfono, email e Instagram

### TÍPICO BUSINESS (privado)
- Acceso con contraseña demo: `demo` o `tipico2026`
- Dashboard de indicadores (marcados como **DEMO**)
- Gestión visual de carta
- Ingeniería de menú (Estrellas / Caballos / Puzzles / Perros) con datos simulados
- Módulo de auditoría (Captación, Operaciones, Ventas, Rentabilidad)
- TÍPICO BUSINESS AI — consultor que distingue hechos / indicadores / hipótesis / recomendaciones

## Datos y fuentes

- Platos iniciales tomados de menciones en prensa y directorios públicos.
- **Pre exos, ingredientes exactos y alérgenos: pendientes de confirmación oficial.**
- No se presentan cifras de ventas reales del restaurante.
- Fotografías: recursos de stock provisionales (Unsplash), no propiedad del restaurante.

## Cómo ejecutar

```bash
npm install
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000).

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- Datos en memoria + localStorage para waitlist (demo)

## Despliegue

Compatible con Vercel / cualquier hosting Node.  
Listo para ampliar con TPV, reservas, WhatsApp Business y CRM.
